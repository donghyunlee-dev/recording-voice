# 개발 완료 절차

개발 완료는 로컬 테스트나 Vercel 빌드만으로 판정하지 않습니다. 배포된 HTTPS 화면을 Windows PC에서 열고, 같은 배포 버전의 로컬 앱을 설치·연결한 뒤 실제 마이크 녹음을 저장하고 다시 재생해야 합니다.

## 현재 실행 상태 (2026-11-04)

- `recording-voice-web.vercel.app`에 현재 작업 트리로 배포했습니다. Vercel CLI가 이 프로젝트의 첫 배포를 Production 대상으로 만들었습니다. 이번 실행은 Preview 검증이나 Production 승격 절차를 통과한 배포가 아닙니다.
- 배포는 Git commit에 고정되지 않은 로컬 작업 트리 산출물입니다. 화면의 프로젝트 ZIP은 GitHub `master`를 받으므로 두 산출물의 전체 소스가 일치한다고 보장하지 않습니다. 설치 스크립트는 현재 `master`의 것과 같지만, 완료 기록에 정확한 소스/배포 SHA 정합 확인은 남겨 둡니다.
- 보호된 사이트는 별도 공유 링크를 통해 2026-11-11까지 열 수 있습니다. 수동 검증 후 링크가 더 필요하면 새 링크를 발급합니다.
- 배포 페이지의 HTTP 200 응답은 확인했습니다. Windows 설치, 연결, 물리 마이크 녹음, 재조회·재생은 아직 실행하지 않아 미완료입니다.

## 1. 배포 준비

- [ ] 변경한 화면의 웹 테스트와 `npm run build`를 통과시킵니다.
- [ ] Vercel 산출물에 모델 파일, 녹음, 대본, 생성 결과가 들어가지 않는지 확인합니다.
- [ ] Vercel Preview를 배포하고 URL, commit SHA, 배포 상태를 기록합니다. 현재 실행은 위의 Production 대상 예외이므로 Preview 완료로 간주하지 않습니다.
- [ ] Windows PC에 받을 프로젝트 ZIP이 Preview를 만든 commit과 같은 소스인지 확인합니다. 소스가 일치하지 않으면 PC 검증을 시작하지 않습니다.

## 2. 사용자 PC에서 설치·녹음

테스트 담당자는 installer를 포함한 Vercel Preview가 준비된 뒤 Windows 10/11 PC의 Chrome에서 그 Preview URL을 열고 다음을 수행합니다. 현재 공개 배포에 이 작업 트리의 installer가 반영됐다고 가정하지 않습니다.

1. **설정 및 설치**에서 `VoiceStudioSetup.exe`를 내려받아 직접 실행합니다. 프로젝트 ZIP, WSL, PowerShell 명령은 사용하지 않습니다.
2. 설치 마법사가 끝나고 backend가 실행되면 사이트로 돌아와 **설치했어요, PC 앱 찾기**를 누릅니다. Chrome의 로컬 네트워크 권한 요청을 승인하고 **이 PC에 연결**을 누릅니다.
3. 사이트의 음성 모델 단계에서 모델 저장소와 라이선스를 확인하고 동의한 뒤 모델 다운로드 진행률과 완료를 확인합니다.
4. **녹음 스튜디오**에서 실제 목소리를 녹음해 PC에 저장합니다.
5. **저장한 녹음**에서 해당 녹음을 다시 불러와 재생합니다. 앱을 다시 열거나 페이지를 새로 고친 뒤에도 목록과 재생이 되는지 확인합니다.
6. 네트워크 요청은 배포 페이지와 `127.0.0.1` 로컬 앱 사이에만 오가는지 확인합니다. 음성·대본·생성 결과가 Vercel이나 외부 추론 API로 전송되지 않아야 합니다.

## 3. 제품 흐름 확인

실제 녹음 확인 후 그 녹음을 선택해 음성 모델 설치, 짧은 한국어 문장 생성, 결과 재생과 WAV 저장까지 확인합니다. 모델 생성이 자원 부족이나 시간 초과로 끝나면 성공으로 표시하지 말고 PC 사양, 경과 시간, 오류, 결과 파일 유무를 기록합니다.

이어서 동화 하나를 열고 장면 이동, 대본 전달, 생성 결과 연결을 확인합니다. 현재 장면별 오디오 동기화와 사용자 스토리 보관이 구현되지 않은 경우 해당 기능까지 완료됐다고 보고하지 않습니다.

## 4. 기록 및 완료 판정

`RUN_LOG.md`에 아래 정보를 남깁니다.

- 배포 URL, Vercel 상태, 배포 commit SHA와 검증한 ZIP의 commit SHA
- Windows 버전, Chrome 버전, installer/backend 버전, Python 버전, PC의 사용 가능 메모리
- Local Network Access와 마이크 권한 결과
- 실제 녹음 저장·재조회·재생 결과와 생성 WAV 정보
- 네트워크에서 관찰한 요청 host, 실패한 단계의 오류와 로그 위치
- 검증자와 검증 날짜

Vercel Preview 성공과 Linux 합성 마이크 테스트는 사용자 PC 검증을 대신하지 않습니다. Windows PC의 실제 녹음 저장·재생 및 로컬 전송 경계가 통과해야 설치·녹음 단계가 완료됩니다. 실제 사용자 take로 한 음성 생성과 재생까지 통과해야 제품 흐름을 완료로 판정합니다. Production 승격은 Preview 검증 결과를 검토한 뒤 별도 배포 단계로 진행합니다.
