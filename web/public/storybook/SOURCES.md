# Storybook illustrations

The application uses the nine `*-kawaii.webp` illustrations in this directory. They were generated for Voice Studio with OpenAI image generation and depict gentle, pastel storybook scenes with rounded, friendly characters. The visual direction is cute Japanese kawaii picture-book art; the illustrations do not reproduce Chiikawa characters or logos.

Each image is 1024 × 1024 WebP, encoded at quality 86. The previous public-domain scans remain in this directory as unused historical assets; they are no longer shown in the application. Their original Wikimedia Commons source and rights information is preserved in Git history.

User recordings, transcripts, and generated speech remain in the local runtime.
