# Windows 설치 안내

Voice Studio는 Windows 10/11 x64용 설치 프로그램으로 로컬 백엔드를 준비합니다. WSL, Docker, Java, 터미널 명령은 필요하지 않습니다.

## 설치

1. 웹 화면에서 **Windows 설치 프로그램 다운로드**를 선택하고 내려받은 `VoiceStudioSetup.exe`를 엽니다.
2. 설치 마법사 안내를 따라 설치를 완료합니다. Python과 CPU용 음성 처리 라이브러리가 추가로 내려받아지므로 인터넷 연결이 필요하며, 첫 설치는 몇 분 이상 걸릴 수 있습니다.
3. 설치가 끝나면 PC 백엔드가 자동 실행되고 Windows 계정에 로그인할 때도 시작됩니다. 설치 파일을 연 브라우저로 돌아와 **설치했어요, PC 앱 찾기**를 누릅니다.
4. 브라우저가 로컬 네트워크 접근 권한을 요청하면 허용하고 **이 PC에 연결**을 누릅니다.
5. Qwen3-TTS 0.6B Base 모델 저장소와 Apache-2.0 라이선스를 확인하고 다운로드에 동의합니다. 약 2.52 GB의 모델 다운로드 진행률이 화면에 표시됩니다. 완료되면 녹음 화면으로 이동합니다.

설치 파일은 모델 가중치를 포함하지 않습니다. 모델은 동의한 뒤 PC의 `%LOCALAPPDATA%\VoiceStudio\models`에 받습니다. 녹음, 대본, 생성 결과는 `%LOCALAPPDATA%\VoiceStudio\data`에 저장됩니다. 브라우저에서 설치 파일을 자동 실행할 수는 없으므로 내려받은 파일을 직접 열어야 합니다.

## 문제 해결

- 설치가 끝나도 앱을 찾지 못하면 설치가 완료됐는지 확인한 뒤 **다시 확인**을 누릅니다.
- 로컬 네트워크 권한 안내가 나오면 사이트의 로컬 네트워크 접근을 허용하고 다시 확인합니다.
- 모델 다운로드에는 8 GiB 이상의 모델 저장 공간이 필요합니다. 모델 실행 전에는 최소 5.7 GiB의 사용 가능 RAM이 필요하며, 음성 처리 중 메모리 사용량은 모델과 시스템 상태에 따라 증가합니다.
- 백엔드 진단 로그는 `%LOCALAPPDATA%\VoiceStudio\logs`에 저장됩니다. 로그에는 녹음 오디오와 대본 내용을 기록하지 않습니다.
- 앱을 제거해도 녹음과 모델 파일은 보존됩니다. 직접 삭제하려면 앱 제거 후 `%LOCALAPPDATA%\VoiceStudio` 폴더를 삭제합니다.
